README 功能截图放置说明
============================================================
请把截图放到本目录（docs\images\），文件名必须与 README.md 中
引用的完全一致（PNG 格式，建议 1920×1080 全屏、浅色主题、浏览器全屏）。

需要的截图（共 5 张，前 3 张必备）：
------------------------------------------------------------
1. 01_home_dashboard.png
   首页仪表盘：初始化成功后，展示 4 个统计卡片（文档片段/索引文件/
   对话会话/准确率）和核心功能区

2. 02_document_management.png
   文档管理页：上传文件后的索引列表（展示文件名、分块数、状态）

3. 03_qa_chat.png（最重要）
   智能问答页：问一个问题并展示 AI 回答，最好把“📚 引用来源”
   展开，能看到来源文件名、相关度、引用片段

4. 04_system_settings.png
   系统设置页：展示检索参数（top_k、混合权重等）可配置

5. 05_clear_history.png（加分项）
   智能问答页侧边栏：点击“🧹 清空全部对话历史”后弹出的
   二次确认提示（“将删除所有会话记录，此操作不可恢复”）

拍摄小贴士：
------------------------------------------------------------
- 启动：双击 run.bat 或执行 streamlit run app/main.py
- 先在首页点“🔧 初始化系统”，再逐页截图
- 建议浅色主题（右上角菜单 ⋮ → Settings → Theme 选 Light）
- 浏览器窗口放大到 1440px 宽以上，折叠侧边栏，避免画面遮挡
- 第 3 张建议用的提问（库中已有语料）：
  “减少幻觉的一种策略是什么？”
  能命中 prompt.txt 并带出引用，演示效果最好

放好后无需改代码，README 里的图片路径已按上面文件名写好。
（本说明文件可以保留，也可以删除。）
